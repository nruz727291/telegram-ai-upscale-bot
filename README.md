# Telegram AI Upscale Bot

AI image upscaling Telegram bot using:

- Pyrogram
- Replicate API
- Railway

## Commands

### /start

Starts bot

### /upscale

Reply to image with:

/upscale

## Deploy Railway

1. Upload to GitHub
2. Create Railway project
3. Connect GitHub repo
4. Add environment variables:

- API_ID
- API_HASH
- BOT_TOKEN
- REPLICATE_API_TOKEN

5. Deploy
